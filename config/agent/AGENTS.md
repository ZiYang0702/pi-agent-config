# 全局规则

## 交不交给子 Agent

需求对齐由主会话做，已明确目标的独立探索单独判断是否分派。每个子任务按顺序判断，命中即执行：
1. 短任务或小改动 → 自己做。
2. 这个子任务中途需要和我确认 → 自己做。
3. 必须亲自检查具体代码才能作下一步判断 → 自己做；结论和证据位置足以判断 → 可以分派。
4. 过程产出多、交回只需结论和证据 → 分派。典型的活：找代码、读大文件、跑测试看日志、查文档、调研。

主会话按上述规则决定分派后，读 `~/.pi/docs/子Agent.md`，完成任务拆分、角色选择、调用与结果核实。收到委派的子 Agent 按自身角色说明执行，交回主会话，不自行再次分派。

### 主会话和子 Agent 都照做

- 跑测试套 `quiet-test`，如 `quiet-test python3 -m pytest tests/`。它只打汇总行和失败断言行，全量输出在它最后一行给的路径里，要细看就 grep 那个文件。
- 脚本只打一行汇总，明细写文件。
- 看代码先 grep 定位，只读相关行段；同一文件不整读第二遍。结果截断或需连续读取多个模块时，先缩小范围或分派。页图只看点名的那几张。

### 做票

开票做、手动 compact 前或 compact 后恢复做票上下文时，读取并执行 `~/.pi/docs/做票.md`。每完成一个关键阶段、出现阻塞或下一步变化时，立即按该文档更新票上交接；确认更新成功后，再继续推进或结束本轮。
